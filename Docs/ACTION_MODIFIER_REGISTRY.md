# 動作與詞條登錄表

> **版本**：1.0  
> **對應 GDD**：[GDD.md](GDD.md) v0.4  
> **用途**：動作本體與修飾詞條的權威名單；企劃填表、數值平衡、未來資料匯出皆以此為準。  
> **狀態標記**：【已確認】= 設計已鎖定；【草案】= 方向已定，數值待調

---

## 0. 維護規則

1. **新增詞條**：先分配唯一 ID（`act_*` 或 `mod_*`）→ 填入對應表格 → 在 §6 變更紀錄加一行。
2. **改數值**：只改【草案】欄位，**不改 ID**。
3. **改語意／規則**：同步更新 [GDD.md](GDD.md) 對應章節與本表備註欄。
4. **狀態升級**：【草案】→【已確認】須 GDD 與本表兩處標記一致。
5. **互斥與槽位**：動作本體互斥群組、3 選 2 槽位限制以 GDD §6.2 為準；本表僅記錄適用範圍。
6. **疊加**：預設修飾詞條可同名線性疊加（GDD §6.3）；若某詞條設為「唯一」或「遞減」，須在疊加規則欄明確標示。

### ID 命名慣例

| 前綴 | 用途 | 範例 |
|------|------|------|
| `act_` | 動作本體 | `act_slash_str` |
| `mod_` | 修飾詞條 | `mod_charge_haste_agi` |
| `fx_` | 狀態／效果（§5） | `fx_stun` |

## 4. 複合詞條（含參數變體）

複合詞條由多個基底效果組成；**顯示名**可含參數占位，**ID** 建議 `{基底}_{參數}` 或共用模板 ID + 參數欄。

### 4.1 模板定義

| 模板 ID | 顯示名模板 | 組成 | 參數 | 屬性 |
|---------|------------|------|------|------|
| `mod_charge_haste_break` | 加速續力-破防 [{break_pct}%] | `mod_charge_haste_agi` + `mod_armor_break_pct` | `break_pct` | AGI |

### 4.2 已登錄變體

| 完整 ID | 模板 ID | 參數值 | 顯示名 | 解鎖後效果摘要 | 狀態 |
|---------|---------|--------|--------|----------------|------|
| `mod_charge_haste_break_30` | `mod_charge_haste_break` | break_pct=30 | 加速續力-破防 [30%] | 續力加速 + 破防 +30% | 【已確認】 |
| `mod_charge_haste_break_20` | `mod_charge_haste_break` | break_pct=20 | 加速續力-破防 [20%] | 續力加速 + 破防 +20% | 【草案】 |
| `mod_charge_haste_break_40` | `mod_charge_haste_break` | break_pct=40 | 加速續力-破防 [40%] | 續力加速 + 破防 +40% | 【草案】 |

【已確認】§6.4 疊加範例：4× `mod_charge_haste_break_30` → 破防 **+120%**（30% × 4，線性加總）。

### 4.3 新增變體步驟

1. 確認模板 ID 已存在於 §4.1。
2. 在 §4.2 新增一行：分配 `mod_{template}_{value}` 完整 ID。
3. 不改模板與基底詞條定義。
4. 於 §6 變更紀錄登記。
