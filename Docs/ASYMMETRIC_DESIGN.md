# 不對稱類 DOTA — DEMO 規則來源

## 0. 文件資訊

【草案】版本 0.1，2026-10-23。來源：負責人在「非對稱遊戲設計」、「完善遊戲設定」聊天中的直接要求，以及本次「以目前遊戲規則製作 DEMO」指示。本文為可執行原型的規格；AI 未將任何段落自行升級為【已確認】。與舊 GDD 的對照見 GDD_RECONCILIATION。

最新要求優先：早期「開局後第 30 分鐘魔王勝利」及「驟死禁止所有復活」已分別被**獨立五分鐘終局**及**任務復活資格保留**取代。

## 1. 不對稱核心概念

【草案】玩家由隨機農莊出生，透過任務、野外與討伐成長，競爭魔王討伐貢獻與最終王位。三條成長路線：英雄（單體、無等級上限）、冒險家（主角加 2～5 同伴）、軍團（隊長與雜兵）。最終可成為玩家魔王，與其餘玩家對抗。

DEMO 是獨立場景 `AsymmetricDemo`，一位本機玩家及三名 AI。既有 `TalentTestArena` 繼續驗證 GDD 的動作／詞條；本場景不宣稱已整合其天賦、動畫或網路系統。

## 2. 陣營與人數

【草案】正式連線人數未決。DEMO 使用 4 位參賽者，本機開局選定成長路線，AI 分配三種路線。同伴／士兵的傷害合併為所屬玩家的討伐貢獻；目前以跟隨模型與合併傷害表現，尚無獨立戰術 AI。

## 3. 勝利與失敗條件

【草案】

| 階段 | 規則 |
|---|---|
| 初始討伐 | 30:00 倒數；截止仍未擊敗初始魔王，全員落敗 |
| 路線選擇 | 擊殺成立立即停止模擬，含任務、冷卻、復活、移動與 AI；有效討伐貢獻最高者選擇魔化或護送 |
| 獨立終局 | 選擇及轉場完成後，啟動完整 05:00；不繼承初始倒數 |
| 魔化勝利 | 其他人永久淘汰且無待執行復活；或摧毀王國水晶；或終局歸零仍存活 |
| 魔化失敗 | 玩家魔王被擊敗，存活最高分玩家獲勝；魔化者只得固定魔化分 |
| 護送成功 | 合法持有者與不可阻擋的王國軍會合；僅最終成功者得護送分，存活者得存活分，全體依總分排名 |
| 護送超時 | 終局歸零尚未完成，全員落敗 |

【草案】魔化時剝奪原獎勵／加護與支援，以失去獎勵筆數增加魔王血量。其他玩家在魔王城外分散重生；轉場不扣任務復活資格，不算擊殺。進入終局時，普通死亡倒數中的玩家立即復活；終局停止普通復活，但任務資格仍有效。

【草案】聖器持有者死亡，聖器掉落；活著的其他玩家可拾取接手，加護隨持有者移轉。王國軍從左下主城出發，位置與進度公開，不可受傷、控制或碰撞阻擋。轉手不重置軍隊進度。

## 4. 地圖與節奏

【草案】60×60 六角格，每格橫向一公尺，採 offset 座標；60 列的實際 Z 跨度約 52 公尺。魔王城位於右上，占全圖約 1/5（要求範圍 1/6～1/4）；人類主城位於左下，只保留主城尺度。中央為峽谷，設中央橋及南北繞行通道，無大量不可通行河流。散布農莊、營地與廢墟。以「黑夜君臨」與「隱城」的空間配置方向作為參考，未重製或匯入其地圖資產。

【草案】中局關閉新任務，現有任務保留進度及完成操作；約第 20 分鐘停止普通任務得分。DEMO 暫用第 12 分鐘關閉接取、第 20 分鐘截止；這些是原型數值。若先觸發終局，普通任務立即關閉。

## 5. 經濟與成長

【草案】任務給分與 XP，部分任務提供復活資格；討伐貢獻獨立記錄，不直接轉成任務分。英雄每級的單體成長較強；冒險家與軍團增加跟隨單位。等級無硬上限。各任務獎勵記為一筆，士兵數量不計入魔化獎勵筆數。

【草案】可調原型數值集中在 `MatchRules`：任務 80 分／100 XP、護送 100 分、存活 80 分、魔化失敗 40 分、復活 8 秒、王國軍 150 秒抵達魔王城。固定魔化分不保證每場排名倒數第二。DEMO 任務為據點互動，採集／跑腿／狩獵與王國／神諭任務尚待擴充。

## 6. 操控與 RTS

【草案】WASD、滑鼠瞄準、左鍵路線攻擊、右鍵遠程範圍攻擊，F 在金色據點互動三秒完成任務。此場景的簡化戰鬥是驗證對局用的替身，不改寫 GDD §3.2 已鎖定的正式動作配置。小兵暫自動跟隨與合併攻擊，尚無完整 RTS 指令。

## 7. 與原型關係及交接

【草案】`AsymmetricMatch.cs` 為純 C# 對局權威；`AsymmetricDemo.cs` 負責畫面、移動、AI、任務位置與 UI。`TalentTestArena` 完整保留。GPT 討論規則時先改本文件與 DESIGN_LOG；Cursor 再更新程式並執行 `Tools/AsymmetricRulesTests`。操作與建置見 DEMO_GUIDE。

## 8. 待決與實作邊界

【草案】正式人數、網路框架、伺服器權威、任務細項、貢獻中的治療／坦傷權重、同分勝負、精確獎勵／加護效果、完整 RTS 與美術仍待定。

原型暫用有效傷害計貢獻、同分取較小玩家 ID；AI 最高貢獻者三秒後自動選路，本機最高者由本人選。沒有替正式版設定選路逾時。後續須把距離、冷卻與任務驗證搬到伺服器；目前純 C# 規則入口信任本機場景呼叫。
