# Missing Asset Store Packages

These `.unitypackage` files are referenced by meta files but the binaries are not in the repository.
Re-download from the Unity Asset Store (My Assets) and place each file at the exact path below.

After placing files, use **GamePJ > Plugin Setup > Import Available .unitypackage Files** in Unity.

| Priority | Package | Target path |
|----------|---------|-------------|
| High | P09 MagicaCloth2 setup | `Assets/P09_Modular_Humanoid/Setup_MagicaCloth2.unitypackage` |
| High | CombatGirls UTS SDF (Unity 6 URP) | `Assets/CombatGirlsCharacterPack/Unity Chan Toon Shader - SDF - Unity6_URP_SwordShield.unitypackage` |
| High | Vefects Shader Graph assets | `Assets/Vefects/Stylized VFX/Shader Graph/Stylized VFX Shader Graph Assets.unitypackage` |
| Optional | CombatGirls UTS SDF (URP) | `Assets/CombatGirlsCharacterPack/Unity Chan Toon Shader - SDF - URP_SwordShield.unitypackage` |
| Optional | CombatGirls UTS SDF (Built-in) | `Assets/CombatGirlsCharacterPack/Unity Chan Toon Shader - SDF - Builtin_SwordShield.unitypackage` |

lilToon is installed via Package Manager at `Packages/jp.lilxyzw.liltoon` — the legacy P09 installer is no longer required.
